# SDSP — Shri Devdaman Seva Planner

A private, installable Progressive Web App for daily and special seva of Sevya Prabhu Shri Devdamanlal.

SDSP is a seva management system — not a generic task list. Nitya seva, vishesh seva, panchang, pranalika, photographs and PDFs all live on this device.

## What you can do

- Follow the default nitya sequence: શંખનાદ, મંગલા, શૃંગાર, રાજભોગ, ઉત્થાપન, સંધ્યા, શયન
- Edit, reorder, duplicate, attach files, and complete or skip each seva
- Plan utsav, manorath and custom vishesh categories with Vikram Samvat, tithi and paksha
- Use day / week / month / year / agenda calendars, then open any date’s seva dashboard
- Keep seva pranalika as written procedures and original PDFs (never rewritten)
- Store photographs and documents in a local file manager with archive, favorites and search
- Back up and restore the entire planner, including files
- Install SDSP on Android as an app and keep working offline

## Privacy

No account. No server of your seva. No ads. No analytics. Data is stored in this browser (IndexedDB). Export a backup if you change devices.

Panchang fields are estimates unless you override them. SDSP never forces an astronomical conversion.
